# cbias2026-plugin

[![npe2](https://img.shields.io/badge/plugin-npe2-blue?link=https://napari.org/stable/plugins/index.html)](https://napari.org/stable/plugins/index.html)
[![Copier](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/copier-org/copier/master/img/badge/badge-grayscale-inverted-border-purple.json)](https://github.com/copier-org/copier)

Demo plugin for the CBIAS 2026 napari workshop.

This [napari] plugin was generated with [copier] using the [napari-plugin-template] (v2.3.0).

## What it demonstrates

The widgets are under **Plugins > CBIAS2026 Demo Plugin** and also in the
**Layers** menu.

- **Five ways to build a widget.** The same image threshold is built as an
  autogenerated function, a `magic_factory`, a live-updating `magic_factory`,
  a magicgui `Container` and a Qt `QWidget` (`src/cbias2026_plugin/_widget.py`).
  They open as tabs in one dock area (`tabify` in the manifest).
- **A workflow widget.** It loads a folder of TIFFs, segments one channel of
  each image and tabulates per-object measurements, using thread workers to
  keep the viewer responsive (`_workflow.py`). Hovering over an object shows
  its measurements in the status bar.
- **Menus.** **Layers > Segment > CBIAS demo** has the threshold widgets and a
  one-click **Segment image** command, which is only enabled when an image
  layer is selected (`_segment.py`).
- **Settings.** The segmentation parameters are in **Preferences > CBIAS2026
  Demo Plugin** (`configurations` in the manifest). The menu command and the
  workflow widget both use them.
- **Sample data.** **File > Open Sample > CBIAS2026 Demo Plugin** has mitotic
  nuclei, a `cells3d` max projection laid out for the workflow widget, and
  synthetic nuclei with ground-truth labels (`_sample_data.py`). The first
  two are downloaded by scikit-image the first time they're opened, so open
  them once beforehand if the session has no internet.
- **Readers and writers.** **File > Save Selected Layers** saves a labels
  layer's measurements as `.csv`, or an image as `.npy`. The reader opens
  integer `.npy` files.

The manifest that wires all of this into napari is
`src/cbias2026_plugin/napari.yaml`.

## Installation

The plugin needs Python 3.13 or later. Clone this repository, then from
inside the clone install the plugin together with napari:

```bash
pip install -e ".[all]"
napari
```

With [uv], use `uv sync` and then `uv run napari`.

## Development

Run the tests with `pytest` (after `uv sync`, use `uv run pytest`), or with
[tox] to match CI.
