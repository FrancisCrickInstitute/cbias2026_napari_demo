# cbias2026-plugin

[![npe2](https://img.shields.io/badge/plugin-npe2-blue?link=https://napari.org/stable/plugins/index.html)](https://napari.org/stable/plugins/index.html)
[![Copier](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/copier-org/copier/master/img/badge/badge-grayscale-inverted-border-purple.json)](https://github.com/copier-org/copier)

Demo plugin for the CBIAS 2026 napari workshop.

This [napari] plugin was generated with [copier] using the [napari-plugin-template] (v2.3.0).

## What it demonstrates

The widgets are under **Plugins > CBIAS2026 Demo Plugin** and also in the
**Layers** menu.

- **Five ways to build a widget.** The same image threshold is built as an
  autogenerated function, a `magic_factory`, a live-updating `magic_factory`,
  a magicgui `Container` and a Qt `QWidget` (`src/cbias2026_plugin/_widget.py`).
  They open as tabs in one dock area (`tabify` in the manifest).
- **A workflow widget.** It loads a folder of TIFFs, segments one channel of
  each image and tabulates per-object measurements, using thread workers to
  keep the viewer responsive (`_workflow.py`). Hovering over an object shows
  its measurements in the status bar.
- **Menus.** **Layers > Segment > CBIAS demo** has the threshold widgets and a
  one-click **Segment image** command, which is only enabled when an image
  layer is selected (`_segment.py`).
- **Settings.** The segmentation parameters are in **Preferences > CBIAS2026
  Demo Plugin** (`configurations` in the manifest). The menu command and the
  workflow widget both use them.
- **Sample data.** **File > Open Sample > CBIAS2026 Demo Plugin** has mitotic
  nuclei, a `cells3d` middle slice laid out for the workflow widget, and
  synthetic nuclei with ground-truth labels (`_sample_data.py`). The first
  two are downloaded by scikit-image the first time they're opened, so open
  them once beforehand if the session has no internet.
- **Readers and writers.** **File > Save Selected Layers** saves a labels
  layer's measurements as `.csv`, or an image as `.npy`. The reader opens
  integer `.npy` files.

The manifest that wires all of this into napari is
`src/cbias2026_plugin/napari.yaml`.

## Installation

The plugin needs Python 3.13 or later. First clone this repository and move into it:

```bash
git clone https://github.com/FrancisCrickInstitute/cbias2026_napari_demo.git
cd cbias2026_napari_demo
```

Then install it with one of uv, conda or pip. All the commands below are run
from inside the clone.

### With uv

[uv] is a fast replacement for `pip` and `venv` that can also install Python
itself.

1. Install uv by following the
   [installation guide](https://docs.astral.sh/uv/getting-started/installation/).
   On macOS and Linux this is:

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

   and on Windows (PowerShell):

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

2. Install everything:

   ```bash
   uv sync
   ```

   This creates a virtual environment in `.venv` (downloading Python 3.13
   if you don't already have it) and installs the exact versions listed in
   `uv.lock`, so everyone gets the same setup. The plugin is installed in
   editable mode, so changes to the code in `src/` are picked up the next
   time napari starts. The test tools are installed too.

3. Start napari:

   ```bash
   uv run napari
   ```

   `uv run` runs a command inside the project's environment, so there is
   nothing to activate. If you prefer, activate the environment instead
   (`source .venv/bin/activate`, or `.venv\Scripts\activate` on Windows)
   and run `napari` directly.

> **Note:** uv can also be used like pip, with `uv venv` to create the
> environment and `uv pip install -e ".[all]"` to install into it. That
> installs the newest allowed versions rather than the ones in `uv.lock`,
> and the next `uv run` changes the environment to match `uv.lock`, so use
> one approach or the other.

### With conda

With conda (or mamba):

```bash
conda env create -f environment.yml
conda activate cbias2026-napari
napari
```

### With pip

```bash
python -m venv .venv
source .venv/bin/activate  # on Windows: .venv\Scripts\activate
pip install -e ".[all]"
napari
```

This uses whichever Python runs `python`, which must be 3.13 or later.

## Development

Run the tests with `pytest` (after `uv sync`, use `uv run pytest`), or with
[tox] to match CI.
